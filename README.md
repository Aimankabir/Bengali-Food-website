# 🪔 Bengaliana - Bengali Cuisine Website

A beautiful, interactive website showcasing authentic Bengali recipes from both West Bengal and Bangladesh. Discover the soul of Bengali cuisine through 18+ traditional dishes with detailed ingredients, step-by-step instructions, and cultural stories.

## 🌟 Features

- **18 Authentic Recipes**: From Shorshe Ilish to Rasgolla, featuring traditional Bengali dishes
- **Interactive Search & Filters**: Search by name, filter by region (West Bengal, Bangladesh, Kolkata, Dhaka, etc.) and type (Fish, Meat, Vegetarian, Sweets, etc.)
- **Recipe Details**: Complete ingredients lists and step-by-step cooking instructions
- **User Ratings**: Rate recipes and see average ratings
- **Favorites System**: Save your favorite recipes
- **Dark/Light Theme**: Toggle between themes for comfortable browsing
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile
- **Bengali Text Support**: Includes Bengali script for authentic representation

## 🍛 Featured Recipes

- **Shorshe Ilish** - Hilsa fish in mustard paste
- **Kosha Mangsho** - Slow-cooked mutton curry
- **Chingri Malaikari** - Tiger prawns in coconut curry
- **Aloo Posto** - Potatoes with poppy seeds
- **Mishti Doi** - Sweetened yogurt from Rajshahi
- **Rasgolla** - Iconic Bengali sweet
- **Kachchi Biryani** - Dhaka's legendary dum biryani
- And 11 more traditional dishes!

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Aimankabir/Bengali-Food-website.git
cd Bengali-Food-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Build for Production

```bash
npm run build
```

## 📱 Usage

- **Browse Recipes**: Scroll through trending and all recipes
- **Search**: Use the search bar to find specific dishes
- **Filter**: Use region and type filters to narrow down recipes
- **View Details**: Click any recipe card to see full details
- **Rate Recipes**: Click stars to rate recipes
- **Save Favorites**: Click the heart icon to save recipes
- **Toggle Theme**: Use the moon/sun button for dark/light mode
